This is an interactive website about Paris. This application is designed to help users learn fun facts about Paris in a fun, interactive, and sticker-board-like way.  

* **How to play:**
  You can click on any of the pictures for a fun fact.

* **Coding languages used:**
  * HTML
  * CSS
  * JavaScript

* **Problems I faced:**
  The pictures/stickers kept overlapping and crowding each other. To fix this, I used AI to help me structure a clean layout for the stickers.

* **What I learned:**
  I learned to build an interactive layout using HTML structure, CSS, and JavaScript.
